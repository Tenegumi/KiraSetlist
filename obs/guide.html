06

방송 중 · 첫 곡 넣어 보기

찾고, 추가하고, 부르기

  1. 노래책 탭을 눌러.
  2. 곡명이나 가수를 검색해.
  3. 곡 옆 +를 눌러.
  4. 리스트 탭으로 돌아가 곡의 부르기를 눌러.

부르기를 누르면 방송 화면의 현재 곡이 바뀌어!

다 부르면 완료 · 다음 곡. 잘못 누르면 되돌리기. 순서는 드래그하거나 위·아래 화살표로 바꿔 줘.

음원은 평소 쓰던 방식으로 재생하면 돼. 이 도구에서는 화면에 보여줄 곡을 직접 골라.
잘 된 모습: 방송 화면에 곡명과 회전하는 앨범 아트가 보여.

노래책에 없는 신청곡은?

리스트 → + 직접 추가를 누르고 곡명을 적어 줘.

가수와 이미지는 넣고 싶을 때만 넣으면 돼. 다음 방송에도 찾고 싶으면 내 노래책에도 저장을 켜 줘.

07

내 방송에 맞추기

공간은 작게, 정보는 딱 필요한 만큼

먼저 ‘표시 구성’부터

공간을 적게 쓰려면 현재 곡만. 앞뒤 곡도 보여주고 싶으면 이전 1곡 + 현재 곡 + 다음 2곡.

크기는 65~75%부터

우측 패널 크기를 움직여 봐. 위치는 오른쪽·위쪽 여백으로 맞춰.

배경은 살짝 비치게

셋리스트 배경 값을 낮추면 더 투명해져. 왼쪽 아래 정보는 좌측 하단 곡 정보에서 켜고 끌 수 있어.

곡 수·테마·회전도 더 바꾸고 싶어

이전 곡은 1개 켜기/끄기, 다음 곡은 0~5개. 우측 패널과 하단 정보 크기는 각각 50~120%. 테마는 딥 퍼플과 라벤더 글라스, 배경은 0~100%까지 조절할 수 있어.

앨범 아트 회전도 켜고 끌 수 있고, 한 바퀴는 15~60초로 정할 수 있어. 아트가 없거나 불러오지 못하면 키라 기본 CD가 표시돼.

마음에 들게 맞췄으면 끝! 설정은 자동 저장돼.
다음 방송에는 OBS만 켜고 곡을 넣으면 돼.

예전 셋리스트도 같이 보여

예전 셋리스트 소스를 꺼 줘. 배경 이미지 자체에 찍혀 있는 목록이라면, 목록이 없는 배경 이미지로 바꿔야 해.

업데이트나 백업은 어떻게 해?

업데이트할 땐 OBS를 먼저 닫고, 새 ZIP을 풀어 install.cmd를 다시 실행해 줘. 같은 설치 폴더를 쓰면 개인 곡과 설정이 남아.

백업은 아래 두 폴더를 함께 복사하면 돼. 복원할 때도 OBS를 닫고 원래 자리로 돌려놓으면 돼.
