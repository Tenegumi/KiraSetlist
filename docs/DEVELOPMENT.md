# 키라 셋리스트

음원 재생·가사 없이 노래책에서 곡을 추가하고 현재 부르는 곡을 직접 지정하는 로컬 방송 도구입니다. 세이로쿠 키라의 노래책 211곡을 2026-10-05에 가져왔습니다. 장르별 중복은 Notion 페이지 ID로 합쳤고, 같은 제목의 다른 버전은 보존했습니다.

## OBS에서 사용

배포 ZIP을 압축 해제한 폴더의 `install.cmd`를 한 번 실행하면 `사용자 폴더/KiraSetlist`에 설치됩니다. 작업 폴더에서는 `dist/KiraSetlist-OBS/install.cmd`입니다. 실행에 필요한 Node 런타임도 포함돼 있어 별도 설치가 필요 없습니다. 업데이트 설치는 개인 리스트와 직접 등록한 아트·곡을 보존합니다. 업데이트할 때는 OBS를 먼저 닫으세요.

처음 한 번 아래 등록을 마치면 이후에는 **OBS만 실행**합니다. 별도 브라우저나 터미널을 열 필요가 없습니다. OBS를 종료하거나 스크립트를 해제하면 이 스크립트가 실행한 프로그램도 종료됩니다. 목록과 설정은 자동 저장됩니다. OBS가 예기치 않게 종료돼도 소유 프로세스를 확인하고 함께 종료합니다.

조작 패널은 `리스트 / 노래책 / 화면 설정` 탭으로 나눴으며, 큰 방송 미리보기는 생략했습니다. 방송 미리보기는 OBS 장면에서 바로 확인합니다.

한글 설치 안내는 설치 폴더의 `OBS-guide.html`과 OBS 패널 아래 `설치·사용 안내` 버튼에서 볼 수 있습니다. 설치 후에는 해당 PC의 실제 파일 경로와 독 주소가 안내서에 자동으로 채워집니다.

- OBS 조작 패널: http://127.0.0.1:4317/control?dock=1
- 개발용 큰 미리보기: http://127.0.0.1:4317/control
- OBS 오버레이: http://127.0.0.1:4317/overlay
- 참고 배경 포함 미리보기: http://127.0.0.1:4317/overlay?preview=1

## OBS 등록

1. `도구 → 스크립트 → +`에서 설치 폴더의 `kira-setlist.lua`를 선택합니다. 이 스크립트가 OBS를 켤 때 프로그램을 숨김 실행합니다.
2. `독 → 사용자 브라우저 독`에 이름 `키라 셋리스트`를 입력하고 설치 폴더의 `OBS-setup.txt`에 있는 **dock-launcher.html의 file:/// 주소**를 붙여넣습니다. 적용 후 독 제목을 끌어 오른쪽에 고정하고 너비를 약 340~460px로 조정합니다. 조작 독은 방송에 나오지 않습니다.
3. 스크립트 창에서 **현재 장면에 오버레이 추가**를 누릅니다. 1920×1080, FPS 30인 투명 브라우저 소스를 추가합니다. 같은 장면에서는 중복 추가하지 않습니다. 기존 캐릭터·배경 위에 놓으세요.
4. 직접 등록하려면 소스 `+ → 브라우저 → 로컬 파일`에서 설치 폴더의 `overlay-launcher.html`을 선택하고 너비 1920, 높이 1080으로 설정합니다. 연결될 때까지 기다렸다가 오버레이를 표시하므로 시작 순서에 영향을 덜 받습니다.

`preview=1`은 참고 배경이 포함된 개발용 화면입니다. 방송 소스로 사용하지 마세요. `보이지 않을 때 소스 종료`, `장면이 활성화되면 새로고침`은 꺼두는 것을 권장합니다.

다른 캔버스 해상도에서는 같은 16:9 비율로 소스 크기를 조정하세요. 반투명 배경은 지원하며, 별도 OBS 소스의 배경을 CSS로 블러 처리하지는 않습니다. 치지직 API나 계정 연동은 필요하지 않습니다.

## 사용

- 곡명·가수·초성 검색 또는 장르 필터 → `+`로 오늘의 리스트에 추가합니다.
- 노래책에 없는 신청곡은 `+ 직접 추가`에서 곡명·가수를 입력합니다. 곡명만 필수이며 앨범 이미지는 선택입니다. 기본은 오늘의 리스트에만 추가하고, `내 노래책에도 저장`을 켜면 다음 방송에서도 `직접 등록` 필터나 검색으로 찾을 수 있습니다. 원본 Notion 노래책은 수정하지 않습니다.
- `부르기`로 현재 곡을 지정하면 회전 디스크와 곡 정보가 표시됩니다. 음원을 재생하거나 감지하지 않습니다.
- `완료 · 다음 곡`은 현재 곡을 완료 처리하고 다음 대기 곡을 현재 곡으로 지정합니다.
- `화면 설정 → 표시 구성`에서 현재 곡만 / 현재 곡 + 다음 2곡 / 이전 1곡 + 현재 곡 + 다음 2곡을 고릅니다. 직접 설정은 이전 곡 1개 ON/OFF와 다음 곡 0~5개를 지원합니다. 숨긴 영역만큼 패널 높이도 줄어듭니다. 표시 설정은 실제 리스트와 현재 곡을 바꾸지 않으며, 완료 순서는 리스트를 재배열해도 유지됩니다.
- 드래그 또는 위·아래 화살표로 순서를 바꿉니다. `되돌리기`는 추가·현재 곡 지정·완료·삭제·순서 변경·비우기를 복원합니다.
- `화면 설정`에서 우측 패널 크기 50~120%, 오른쪽·위쪽 여백, 하단 곡 정보 크기 50~120%를 따로 조절합니다. 우측 패널 기본값은 75%입니다. 긴 제목이나 많은 표시 곡 때문에 화면 밖으로 나가면 위치·크기를 자동으로 보정합니다. `크기·위치 기본값으로`는 표시 곡 수를 유지한 채 배치만 초기화합니다.
- OBS 조작 독 자체는 중앙 미리보기와 독 사이 경계선을 끌어 너비를 조절합니다. 독 제목을 끌어 분리하면 독립 창으로 띄우고 창 테두리로 크기를 조절할 수 있습니다. 좁은 독에서는 버튼과 메뉴가 줄바꿈됩니다.
- 테마, 배경 불투명도, 좌측 하단 정보 ON/OFF, 회전 여부·속도, 작은 체크 포인트도 설정할 수 있습니다.
- 브라우저가 운영체제의 동작 줄이기 설정을 전달하는 경우 회전 애니메이션은 정지합니다.

## 앨범 아트

`npm run artwork`는 공식 iTunes Search API에서 곡·가수 후보를 가져옵니다. 요청은 약 3.2초 간격으로 제한합니다. 한국 음악은 미국 카탈로그, 일본 음악은 일본 카탈로그를 조회합니다. 제목과 가수가 모두 일치할 때만 자동 연결하며, acoustic/rock 버전 불일치는 확정하지 않습니다. 같은 아티스트의 다른 언어 발매는 자동 결과에서도 확인이 필요합니다.

`아트 미등록`으로 필터링하고 곡 옆 이미지를 누르면 앨범 후보 선택 및 JPG/PNG/WebP 직접 등록을 할 수 있습니다. 원본 노래책의 가수 오류나 미기재 값은 보존하며, 검색용 별칭만 별도로 씁니다. 미확보 이미지는 다른 앨범으로 대신 채우지 않습니다.

직접 추가한 곡에 이미지를 등록하지 않았거나 원본 노래책의 아트가 없는 경우, 제공받은 키라 CD 이미지(`public/default-art.png`)를 공통 기본 아트로 표시합니다. 외부 이미지 로딩 실패도 이 이미지로 대체합니다. 현재 곡의 기본 CD도 회전하며, `아트 미등록` 필터는 실제 곡의 아트가 등록됐는지를 계속 구분합니다.

외부 카탈로그 이미지는 URL로 연결되어 인터넷이 필요합니다. 직접 등록한 이미지는 PC에 저장됩니다. 외부 검색 제공자의 이용조건과 방송 사용 범위를 확인하고, 필요한 경우 허용된 이미지로 교체해 주세요. 조회 기능은 방송 사용 허락을 제공하지 않습니다.

## 저장·백업

- `data/songbook.raw.json`: 가져온 원본 목록
- `data/artwork.json`: 아트와 후보·출처
- `data/state.json`: 현재 곡·목록·직접 등록한 곡·설정·되돌리기 기록
- `data/state.json.bak`: 이전 저장 상태
- `public/artwork/`: 직접 등록한 이미지

설치 버전의 데이터는 설치 폴더 아래 위 경로에 저장됩니다. 업로드 이미지까지 포함한 백업은 설치 폴더의 `data`와 `public/artwork`를 복사하세요. 개발용 화면의 `백업` 버튼은 목록·설정·아트 정보를 JSON으로 내려받지만 OBS 독의 다운로드 동작은 브라우저와 다를 수 있습니다. JSON 가져오기 UI는 현재 포함하지 않습니다. 노래책은 이번에 가져온 스냅샷이며 Notion 변경 사항을 자동 동기화하지 않습니다.

`npm test`로 목록·버전 보존, 완료/순서 변경/삭제 되돌리기, 재실행 복구, 이미지 형식 검증과 OBS 시작 대기 연결을 확인할 수 있습니다. `powershell -File test/install.test.ps1`은 임시 폴더에서 재설치 시 개인 곡·아트 보존과 코드 업데이트를 검증합니다. 실제 OBS 32.2.2에서는 오른쪽 독 등록, OBS 종료 시 자동 실행 서비스 종료, 재실행 시 자동 시작·리스트 복원, 오버레이 소스 추가와 하단 곡 정보 ON/OFF를 확인했습니다. 서버는 127.0.0.1에만 열립니다.

`test/browser-smoke.mjs`는 별도 임시 데이터와 헤드리스 브라우저에서 새 표시 프리셋, 다음 5곡, 크기 슬라이더, 배치 초기화, 260px 독과 설치 안내 열기를 검증합니다. 사용자의 OBS나 마우스를 조작하지 않습니다. Playwright 모듈 경로는 `KIRA_PLAYWRIGHT_PATH`로 지정할 수 있습니다. 이번 크기·표시 곡 수 변경은 이 테스트와 저장·복원 테스트로 검증했으며, 변경 후 실제 OBS 화면을 자동 조작해 확인하지는 않았습니다.

개발 실행은 Node.js 22 이상에서 `npm start`로 합니다. 배포 패키지는 `powershell -File scripts/package-obs.ps1`로 만들며 빌드 PC의 Node 런타임과 라이선스를 포함합니다. 설치 파일은 별도 브라우저를 자동으로 열지 않습니다.

공식 참고: [OBS 브라우저 소스](https://obsproject.com/kb/browser-source), [iTunes 검색 API](https://developer.apple.com/library/archive/documentation/AudioVideo/Conceptual/iTuneSearchAPI/Searching.html).
