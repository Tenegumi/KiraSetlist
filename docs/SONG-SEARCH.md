# 노래책 검색 편의 기능

영문 제목의 한글 발음과 한/영 자판 오입력을 함께 검색합니다. 검색어를 입력하는 동안 기존 노래책 목록에 결과가 바로 나타나며, 입력한 검색어와 실제 곡 제목을 임의로 바꾸지는 않습니다.

| 입력 | 찾는 곡 예시 |
| --- | --- |
| `버터플라이` | `Butter-Fly`, `Butterfly Kiss`, 직접 등록한 `버터플라이` |
| `qjxjvmffkdl` | 같은 결과. 한글 자판에서 ‘버터플라이’를 입력하는 키입니다. |
| `버터ㅍ`, `qjxjv`, `ㅂㅌㅍㄹㅇ` | 입력 중인 글자·자판·초성에 맞는 후보 |
| `배드애플`, `데이식스` | `Bad Apple!!`, `DAY6` 가수의 곡 |

대소문자·띄어쓰기·하이픈과 기존 초성·가수명·일본어 검색도 지원합니다. 장르 및 앨범 아트 미등록 필터, 직접 등록한 노래책의 공개 범위는 유지합니다. 검색 결과의 + 버튼은 원래 곡 ID를 추가하므로 제목·가수·이미지·기존 목록을 바꾸지 않습니다.

검색은 브라우저에서 처리하며 검색어 입력으로 서버 API를 호출하지 않습니다. 조작 독만 새로고침하면 적용되고 기존 키와 주소를 계속 사용합니다.

영문 한글 발음은 명시한 별칭과 공통 단어 사전을 사용합니다. 임의의 모든 영문 제목의 발음을 자동으로 알아내는 기능은 아닙니다. 별칭을 추가하려면 `app/public/search-aliases.js`를 수정합니다. 한/영 자판 보정은 별칭 여부와 관계없이 한글 제목·가수 및 등록된 한글 별칭에 적용됩니다.

로컬 구현은 `app/public/song-search.js`와 `app/public/control.js`에서 사용합니다. 웹 배포용 생성기도 동일한 검색 모듈을 복사합니다. 검증: `app/test/song-search.test.mjs`, `experiments/previous-history/verify-search-local.mjs`, `experiments/previous-history/verify-search-live.mjs`.
