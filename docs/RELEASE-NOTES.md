# v1.2.0 · 원본 + 앰프 DLC 통합본

원본과 앰프 DLC를 하나의 설치 프로그램과 OBS 조작 독에서 선택할 수 있어요. 기존 노래책·현재 곡·오늘의 리스트를 함께 쓰고, 두 디자인의 화면 설정은 따로 저장해요.

- **설치하기.exe → 설치하고 OBS에 적용**으로 런타임·자동 시작 Lua·독·오버레이를 등록해요. 기존 장면 모음은 보관하고 OBS 설정을 백업해요.
- 두 디자인 모두 **3840×2160 브라우저 소스 / 60fps**로 렌더링하고 기존 방송 캔버스에 맞춰 축소해요.
- DLC의 이전·대기 곡은 제목만 표시하고 현재 곡은 가수명을 유지해요.
- DLC LP 슬리브 마크를 키라 의상 느낌의 붉은 하트로 바꿨어요. 하프 LP와 곡 정보가 함께 전환돼요.
- 원본으로 전환할 때 방송 배경이 검게 출력되던 iframe의 색상 구성 오류를 수정했어요.
- 소개·설치 안내·앱 내 도움말과 실제 화면 캡처를 통합본에 맞췄어요.
- 도트 남궁우가 움직이는 **32장면 / 3분 12초** 가이드, **Full HD 안내 이미지 128장**, SRT·대사·HTML 뷰어를 함께 배포해요.

설치·재설치 보존, 디자인 전환 시 목록 보존, 디자인별 화면 설정 저장, 실제 OBS 투명 배경과 4K/60fps 출력, 가이드 화면 넘침과 이미지 로딩을 확인했어요. 배포 ZIP에는 개인 목록과 OBS 설정·비밀번호를 포함하지 않아요.

v1.0.0과 v1.1.0은 이전 원본 설치와 가이드 기록으로 Releases에 남아 있어요. 새로 시작할 때는 v1.2.0 통합 설치 ZIP을 받아 주세요.
