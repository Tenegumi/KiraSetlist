# v1.0.0

Windows OBS에서 사용하는 키라 셋리스트 첫 배포입니다.

- OBS 시작 시 자동 연결되는 조작 독과 투명 방송 오버레이
- 노래책 211곡 검색, 초성·장르 필터, 신청곡 직접 추가
- 현재 곡 지정·완료·순서 변경·되돌리기와 자동 저장
- 현재 곡 앨범 아트 회전 및 키라 기본 CD 대체 이미지
- 이전 곡 ON/OFF, 다음 0~5곡, 현재 곡만 표시
- 우측 패널·좌측 하단 정보의 크기와 위치 설정, 반투명도와 테마
- 스크린샷을 넣은 설치·사용 가이드와 Node 런타임 포함 ZIP

설치 방법은 저장소의 `docs/INSTALL.md` 또는 ZIP 안의 `OBS-guide.html`을 참고하세요. 처음 설치한 뒤 OBS에 스크립트·독·오버레이를 한 번 등록하면, 이후에는 OBS만 실행하면 됩니다.

검증: Node 자동 테스트 11개, 재설치 시 개인 데이터 보존, 헤드리스 브라우저의 표시 구성·260px 독·설치 안내, 실제 OBS 32.2.2의 시작·종료와 데이터 복원. 음원 재생과 가사 싱크 기능은 포함하지 않습니다.
