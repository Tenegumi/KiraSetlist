# v1.2.3 · 누적 핫픽스 (2026-10-24)

웹에 먼저 반영했던 수정과 새 표시 기능을 공개 저장소·수동 ZIP·자동 설치 ZIP에 맞췄어요. [전체 핫픽스 기록](HOTFIXES.md)에서 HF-01~HF-12의 변경 내용을 확인해요.

- 이전·다음 곡의 줄 수를 각각 지정하고 자동 슬라이드를 각각 멈출 수 있어요. 기본은 이전 2곡·다음 1곡이에요.
- PREVIOUS는 제목 흐름을 유지하고 숫자만 01부터 연속 표시해요. 원래 1·7·9·2·3번 곡이면 표시 번호는 01·02·03·04·05예요.
- UP NEXT와 완료 진행은 현재 곡 뒤의 대기 곡만 사용해요. 건너뛴 앞쪽 곡을 끼워 넣거나 목록 끝에서 앞으로 돌아가지 않아요.
- 한글 발음 별칭·한/영 자판 보정·입력 중 자동완성을 추가했어요. 버터플라이와 qjxjvmffkdl 검색을 지원해요.
- 튕기는 전환은 오른쪽 앰프에만 유지하고 왼쪽 LP·제목은 전환 모션 없이 교체해요.
- 기존 웹의 키·URL·목록을 유지하는 업데이트와 실제 표시 소스의 캐시 새로고침 방법을 안내해요.
- 10월 5~6일 웹에 먼저 적용한 연결·보안·사용량·Notion 수동 갱신·OBS 버전 호환 수정도 누적 기록에 포함했어요.
- 웹 SDK와 하위 의존성의 보안 패치를 반영했어요. 배포 전 npm audit에서 보고된 취약점은 0건이에요.

기존 웹 사용자는 새 키를 발급하지 말고 [업데이트 안내](WEB-UPDATE.md)를 따라 주세요. 로컬은 방송 종료 후 개인 데이터 폴더를 백업하고 프로그램 파일을 바꿔요. 자동 설치는 OBS의 방송 프로필·해상도·FPS·인코더·방송 키를 변경하지 않아요.

## v1.2.2 · 제목이 더 잘 보이는 셋리스트

- 웹과 로컬 DLC를 **굵은 앰프** 디자인으로 맞췄어요.
- 현재 곡은 큰 제목과 흰색 카드로 강조하고, 이전·대기 곡은 제목만 굵고 촘촘하게 표시해요.
- 긴 대기 곡명은 두 줄까지 표시해요. 현재 곡 제목은 최대 세 줄이며 가수명도 유지해요.
- 원본도 제목을 더 크게·굵게 표시하고 목록 간격을 줄였어요. 원본 방송 화면은 현재·이전·대기·왼쪽 하단의 가수명을 모두 빼고 제목만 표시해요. 조작 독과 노래책에는 가수 정보가 남아요.
- 기존 곡 목록·화면 설정, 4K/60fps 렌더링과 LP 전환을 유지해요.
- 수동 ZIP과 자동 설치 ZIP 모두 새 디자인이 포함돼요.

## v1.2.1 · 설치 방법을 선택해요

- 설치 프로그램이 없는 **수동 ZIP**과 독·스크립트·브라우저 소스 연결 가이드를 추가했어요.
- 통합 설치에서 이전 키라 독이 함께 남던 문제를 수정했어요. 이름과 주소가 맞는 이전 키라 독만 정리해요.
- 자동 설치가 방송 프로필 FPS를 60으로 덮어쓰던 동작을 제거했어요. 프로필 파일은 그대로 보존해요.
- OBS 경로 선택과 포터블 설정 폴더 인식을 추가했어요. 잘못된 경로는 설정을 쓰기 전에 멈춰요.
- 소개 화면에서 자료 묶음 링크를 빼고 튜토리얼과 두 전환 MP4를 바로 재생하도록 넣었어요.
- 수동 연결을 1순위, 자동 설치를 2순위로 안내해요. 움직이는 튜토리얼을 **36장면 / 3분 36초**로 다시 만들었어요.

## v1.2.0 · 원본 + 앰프 DLC 통합본

원본과 앰프 DLC를 하나의 설치 프로그램과 OBS 조작 독에서 선택할 수 있어요. 기존 노래책·현재 곡·오늘의 리스트를 함께 쓰고, 두 디자인의 화면 설정은 따로 저장해요.

- **설치하기.exe → 설치하고 OBS에 적용**으로 런타임·자동 시작 Lua·독·오버레이를 등록해요. 기존 장면 모음은 보관하고 OBS 설정을 백업해요.
- 두 디자인 모두 **3840×2160 브라우저 소스 / 60fps**로 렌더링하고 기존 방송 캔버스에 맞춰 축소해요.
- DLC의 이전·대기 곡은 제목만 표시하고 현재 곡은 가수명을 유지해요.
- DLC LP 슬리브 마크를 키라 의상 느낌의 붉은 하트로 바꿨어요. 하프 LP와 곡 정보가 함께 전환돼요.
- 원본으로 전환할 때 방송 배경이 검게 출력되던 iframe의 색상 구성 오류를 수정했어요.
- 소개·설치 안내·앱 내 도움말과 실제 화면 캡처를 통합본에 맞췄어요.
- 도트 남궁우가 움직이는 **32장면 / 3분 12초** 가이드, **Full HD 안내 이미지 128장**, SRT·대사·HTML 뷰어를 함께 배포해요.

설치·재설치 보존, 디자인 전환 시 목록 보존, 디자인별 화면 설정 저장, 실제 OBS 투명 배경과 4K/60fps 출력, 가이드 화면 넘침과 이미지 로딩을 확인했어요. 배포 ZIP에는 개인 목록과 OBS 설정·비밀번호를 포함하지 않아요.

v1.0.0과 v1.1.0은 이전 원본 설치와 가이드 기록으로 Releases에 남아 있어요. 새로 시작할 때는 최신 v1.2.3 수동 ZIP을 먼저 선택해 주세요.
