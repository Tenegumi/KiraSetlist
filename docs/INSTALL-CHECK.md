# 자동 설치가 바꾸는 것, 유지하는 것

**v1.2.1 기준**이에요. 설치는 OBS가 완전히 종료되어 있을 때만 진행해요. OBS를 바꾸고 싶지 않다면 [수동 ZIP](MANUAL.md)을 골라 주세요.

| 자동 설치가 하는 일 | 범위 |
| --- | --- |
| 프로그램 복사 | 기본 `사용자 폴더/KiraSetlistUnified` · Node 포함 |
| 새 장면 모음 추가 / 선택 | 기존 방송 모음을 복사한 **키라 통합 셋리스트 (원본 + DLC)** |
| 소스 / 스크립트 등록 | 새 모음에 3840×2160·60fps 브라우저 소스와 자동 실행 Lua |
| 조작 독 등록 | 통합 독 1개 · 알려진 예전 키라 독의 이름과 주소가 모두 맞으면 등록 제거 |
| 설정 백업 | 선택한 OBS 설정 폴더의 `kira-install-backups` |

**방송 해상도, 방송 FPS, 인코더, 비트레이트, 오디오, 방송 키는 수정하지 않아요.** 기존 장면 모음 파일과 다른 조작 독도 보존해요. 예전 앱 폴더도 삭제하지 않아요. 독 등록은 OBS 전체에 적용되므로 예전 키라 독 정리는 이전 장면 모음에서도 보일 수 있어요.

v1.2.0 설치는 프로필 FPS를 60으로 바꿨어요. v1.2.1은 이를 제거했어요. 이미 설치했다면 현재 FPS를 자동 복원하지 않으므로 원하는 방송 FPS를 OBS 설정 → 비디오에서 직접 확인해 주세요.

## OBS가 다른 곳에 설치되어 있다면

설치 창의 **OBS 경로 선택**에서 사용하는 `obs64.exe`를 골라요. 예: `D:\방송 도구\OBS\bin\64bit\obs64.exe`. 기본 설치 경로와 설치 레지스트리 위치는 자동으로 찾지만, 여러 OBS가 있으면 직접 선택하는 편이 확실해요.

<img src="../app/public/guide-assets/installer.png" alt="OBS 경로 선택과 포터블 체크가 있는 실제 설치 프로그램 화면" width="600">

일반 설치 OBS는 실행 파일 위치가 달라도 `%APPDATA%\obs-studio` 설정을 사용해요. 포터블은 선택한 OBS 폴더의 `config/obs-studio`를 사용해요. `portable_mode` 등의 표식은 자동 감지해요. `--portable` 옵션으로만 여는 OBS는 **포터블 OBS**에 체크해요. [OBS 공식 포터블 안내](https://obsproject.com/kb/portable-mode)

선택한 OBS의 설정이 없거나 실행 파일이 잘못되면 **OBS 설정을 쓰기 전에 중단**해요. 포터블 설정이 없다고 일반 OBS 설정으로 넘어가지 않아요. 선택한 OBS를 한 번 열고 닫은 다음 다시 시도해 주세요.

## 확인한 결과

| 경우 | 확인 방법 / 결과 |
| --- | --- |
| 일반 OBS 경로 | 기본 AppData 설정을 대상으로 설치 테스트 통과 |
| 별도 드라이브 형태 · 한글/공백 경로 | 임시 OBS 디렉터리에서 명시한 exe 경로 해석 및 설치 통과 |
| 포터블 표식 / 강제 포터블 | 임시 포터블 설정에만 쓰기 · 일반 OBS 설정은 바이트 단위로 동일 |
| 경로 없음 / 포터블 설정 없음 | 중단 · 일반 OBS 설정 보존 |
| 재설치 | 개인 목록·아트 보존 · 통합 소스/독 중복 없음 |
| 이전 키라 독 + 다른 독 | 이전 독만 제거 · 채팅과 이름만 같은 사용자 독 보존 |
| 방송 프로필 | 30fps 테스트 프로필 파일 전체가 설치 전후 동일 |
| PowerShell 설치 진입점 | 격리한 사용자 설정에서 포터블 지정 · NoLaunch 설치 통과 |
| 실행 중인 OBS | 실제 설치 명령에서 중단 확인 · 설정 변경 없이 종료 |

경로별 검증은 격리된 임시 OBS 설정을 이용한 테스트예요. 모든 PC의 보안 프로그램, 권한, OBS 플러그인 조합까지 검증한 것은 아니에요. Windows용이며 실제 출력은 OBS 32.2.2에서 확인했어요. 브라우저 소스와 Lua 스크립트 기능이 없는 OBS 배포판은 수동 방식도 사용할 수 없어요.
