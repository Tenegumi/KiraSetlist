# 방송 중 셋리스트 업데이트하기

운영 웹: https://kira-setlist-web.vercel.app/

기존 운영 웹을 쓰고 있다면 새 키를 받거나 OBS 주소를 바꿀 필요가 없어요. 기존 목록과 화면 설정도 그대로예요. OBS나 방송을 종료하지 않고 아래 두 곳만 새로고침해 주세요.

1. **조작 화면:** 오른쪽 셋리스트 독의 빈 곳을 마우스 오른쪽 버튼으로 누르고 **새로고침**을 눌러요. 독 제목 표시줄 대신 곡 목록이 있는 웹페이지 안의 빈 곳을 눌러 주세요.
2. **방송 화면:** OBS 소스 목록에서 셋리스트 브라우저 소스를 선택하고, 미리보기 아래에 있는 **새로고침**을 눌러요. 버튼이 보이지 않으면 그 소스의 **속성 → 현재 페이지의 캐시 새로고침**을 사용해요.

방송 송출은 계속되지만 셋리스트 오버레이가 잠깐 사라졌다가 돌아올 수 있어요. 곡 사이에 해 주세요. 새로고침하지 않은 화면은 기존 코드로 곡 변경을 계속 받으며, 배포가 강제로 화면을 다시 불러오지는 않아요.

조작 독을 새로 열거나 새로고침하면, 저장된 표시 옵션과 관계없이 **이전 2곡 + 다음 1곡 + 이전·다음 자동 슬라이드 켜짐**이 적용돼요. 곡 목록·현재 곡·완료 기록과 패널 크기·위치·투명도는 유지해요. 방송 중 곡 변경이나 연결 재시도만으로 표시 옵션을 초기화하지는 않아요.

업데이트된 조작 화면의 **화면 설정**에서 이전·다음 곡 줄 수를 각각 바꾸고, 자동 슬라이드도 각각 켜거나 끌 수 있어요. 해당 사용 중에는 변경한 옵션을 유지하며, 조작 독을 다시 새로고침하면 위 기본 구성으로 돌아가요. 이전 곡에 남기려면 **완료 · 다음 곡**으로 진행해 주세요.

**UP NEXT는 현재 곡 뒤의 대기 곡만 표시해요.** 14번 곡을 부르면 15·16·17번처럼 뒤의 곡을 순환하고, 앞에 미완료로 남아 있는 13번을 끼워 넣지 않아요. **완료 · 다음 곡**도 현재 곡 뒤의 대기 곡으로 진행해요. 다음 곡이 없으면 ‘대기 곡이 없어요’가 나오고, 마지막 곡 이후 앞쪽으로 자동 순환하지 않아요. 건너뛴 곡은 목록에 보존되므로 다시 부르려면 그 곡의 **부르기**를 눌러 주세요.

**PREVIOUS는 기존 곡 흐름을 유지하고 앞 번호만 01부터 연속으로 붙여요.** 원래 곡 번호가 1→7→9→2→3 순서로 섞여 있어도 제목 순서는 그대로 두고, PREVIOUS의 표시 번호만 01→02→03→04→05가 돼요. 완료한 곡이 12개면 표시 번호는 01~12예요. 제목을 오른쪽 목록 순서로 다시 정렬하지 않아요. 원래 목록과 완료 기록은 유지하고 UP NEXT 번호도 기존 목록 번호를 사용해요.

이 표시 수정만 받으려면 **현재 화면에 보이는 셋리스트 브라우저 소스**의 **속성 → 현재 페이지의 캐시 새로고침**을 눌러요. 숨겨진 다른 브라우저 소스나 조작 독만 새로고침하면 방송 화면이 갱신되지 않아요. 키나 URL을 다시 발급할 필요는 없어요.

새 키를 발급하면 새 목록을 쓰는 별도 공간이 생겨요. 단순 업데이트에는 새 키 발급을 사용하지 마세요. `kira-setlist-test.vercel.app`의 테스트 공간은 운영 공간과 별개이므로 테스트 주소를 운영 주소로 바꾸기만 해서 목록을 옮길 수는 없어요.

OBS 근거: [브라우저 독의 우클릭 새로고침](https://github.com/obsproject/obs-studio/releases/tag/27.0.0), [브라우저 소스의 캐시 새로고침](https://obsproject.com/kb/browser-source).
