# v1.2.3 누적 핫픽스 기록

배포일: **2026-10-24**. 웹에 순차 적용한 수정들을 공개 코드·설명서·로컬 다운로드에 반영한 누적 버전이에요. HF-01~HF-12는 수정 항목을 구분하는 기록이며, 각각 별도 ZIP이나 Git 태그가 있다는 뜻은 아니에요. v1.2.2와 이전 릴리스는 [이전 기록](RELEASE-NOTES.md)에 남겨요.

## HF-01 · 웹부터 연결하는 사용법

- 첫 번째 방법은 [웹 셋리스트](https://kira-setlist-web.vercel.app/)예요. 설치 없이 개인 조작 독·읽기 전용 방송 주소를 발급해 OBS에 붙여요.
- 두 번째 방법은 로컬 수동 ZIP, 자동 설치는 선택 사항으로 안내해요.
- 첫 화면의 사용 방법을 강조하고 버튼을 **OBS 입력할 링크 발급하기**로 맞췄어요.

## HF-02 · 웹 링크 발급과 실시간 연결 복구

- 저장소 오류로 링크 발급이 실패하던 흐름을 수정하고 지속 저장을 Redis로 옮겼어요.
- 곡 추가·설정 변경·다음 곡은 해당 개인 공간에 저장하고 변경 알림으로 반영해요.
- 재연결은 알림 구독 후 최신 상태를 받아 누락을 복구해요. 열린 화면은 마지막 곡을 유지하고 실패한 조작을 임의 재실행하지 않아요.

## HF-03 · 켜 두었을 때 반복 조회 줄이기

- 초당 상태 조회·revision 폴링·Vercel의 장시간 이벤트 중계를 제거했어요.
- 브라우저가 자신의 채널만 읽는 Upstash 구독으로 변경 알림을 받아요. 정상 대기 중 유지용 Vercel API 호출은 하지 않아요.
- 처음 로딩·이미지 전송·사용자 조작·재연결·저장·서비스 구독에는 사용량이 발생할 수 있어요. 표시 애니메이션과 검색은 브라우저 안에서 처리해요.

## HF-04 · 노래책은 요청할 때만 갱신

- Notion 매일 자동 갱신을 중단하고 운영자 요청에 의한 수동 갱신으로 바꿨어요.
- 새 곡·수정 정보를 반영하면서 원본에서 삭제된 곡도 보존해요. 개인 리스트·직접 등록 곡·기존 앨범 아트는 유지해요.
- 원본을 불완전하게 읽었거나 조회에 실패하면 마지막 성공 목록을 유지해요.

## HF-05 · 개인 공간·키·요청 보안

- 조작 키와 읽기 전용 보기 키를 구분하고 다른 개인 공간의 변경·조회 권한을 분리했어요.
- 키는 URL fragment와 인증 헤더로 전달하고 공개 쿼리에 넣지 않아요. 구독 키도 자기 채널의 읽기 권한만 갖게 했어요.
- 요청 출처·형식·크기 제한, 충돌 감지와 인증 오류 시 재시도 중단을 적용했어요. 이전 반복 조회 방식은 저장소 접근 전 거절해요.
- 과거 운영자 요청에 따른 키 폐기 작업과 이번 UI 업데이트는 별개예요. **이번 핫픽스를 받기 위해 현재 키를 폐기하거나 재발급하지 않아요.**

## HF-06 · OBS 브라우저 호환과 캐시

- HTML·JavaScript·CSS·모듈의 배포 버전을 맞추고 이전 문서와 새 연결 코드가 섞였을 때 한 번 복구하는 처리를 넣었어요.
- 기존 주소·키와 화면 옵션을 유지해요. 이미 열린 페이지가 새 코드를 전혀 받지 않았다면 사용자가 한 번 새로고침해야 해요.
- 실제 보이는 브라우저 소스의 **속성 → 현재 페이지의 캐시 새로고침**을 안내해요. 숨겨진 다른 소스나 조작 독을 갱신하는 것과 구분해요.
- 원본 iframe의 투명 배경, 두 디자인의 4K/60fps 브라우저 소스 렌더링을 유지해요.

## HF-07 · 굵은 제목과 앰프 전환 정리

- 원본·앰프의 제목을 굵게 하고 이전·대기 곡의 가수명을 숨겼어요. 원본 방송 화면의 가수명도 숨겨요. 노래책과 조작 독에는 가수 정보가 남아요.
- 앰프의 붉은 하트 슬리브·반쯤 나온 LP·사인 스타일을 유지해요.
- 곡 전환의 튕김은 오른쪽 앰프에만 적용해요. 왼쪽 하단 LP·제목·가수·사인은 평범하게 교체하고 평소 LP 회전은 유지해요.

## HF-08 · 이전·다음 줄 수와 독립 슬라이드

- 이전 곡은 영역 ON/OFF와 1~5줄, 다음 곡은 0~5줄로 지정해요. 2·2, 3·3 프리셋과 직접 설정을 제공해요.
- 표시 줄 수보다 곡이 많으면 해당 영역 안에서 4초마다 한 줄씩 순환해요. 이전·다음 자동 슬라이드를 각각 멈출 수 있어요.
- 조작 독을 새로 열거나 새로고침할 때 **이전 2곡·다음 1곡·양쪽 슬라이드 켜짐**을 적용해요. 이 다섯 표시 항목 외의 곡 자료·위치·크기·투명도는 유지해요.
- 사용 중 바꾼 옵션은 연결 재시도나 곡 변경만으로 초기화하지 않아요. 자동 슬라이드는 서버 조회를 추가하지 않고 숨겨진 창에서는 멈춰요.

## HF-09 · UP NEXT와 완료 진행 순서

- 현재 14번이면 뒤의 대기 곡 15·16·17번만 표시해요. 앞쪽에 미완료로 남겨 둔 13번은 끼워 넣지 않아요.
- **완료 · 다음 곡**도 현재 위치 뒤로 진행해요. 마지막 곡 뒤에는 대기 곡 없음으로 표시하고 과거 미완료 곡으로 자동 이동하지 않아요.
- 건너뛴 곡을 삭제하거나 임의 완료 처리하지 않아요. 다시 부를 때는 그 곡의 **부르기**를 선택해요.

## HF-10 · PREVIOUS 전용 연속 번호

- 곡 제목의 흐름은 그대로 두고 **앞 숫자만 독립적으로 01부터** 붙여요.
- 원래 번호가 **1 → 7 → 9 → 2 → 3**인 곡을 불러도, 제목 순서는 그대로이며 PREVIOUS 번호는 **01 → 02 → 03 → 04 → 05**예요.
- 12곡을 완료했으면 표시 번호는 01~12예요. 원래 목록 번호·현재 곡·완료 기록을 바꾸거나 제목을 재정렬하지 않아요.
- UP NEXT는 계속 실제 목록 번호를 사용해요. 완료·되돌리기와 줄 수 변경에도 반영해요.

## HF-11 · 검색 편의와 설치 안내

- 한글 발음 별칭을 등록한 영문 제목과 한/영 자판 오타를 찾아요. `Butter-Fly`는 **버터플라이**, **qjxjvmffkdl**로 검색해도 나와요.
- 부분 입력·초성·영문·일본어·가수 검색과 장르 필터를 유지해요. 모든 영문 제목을 자동 번역·음역하는 기능은 아니에요. [검색 안내](SONG-SEARCH.md)
- 수동 ZIP과 자동 설치 ZIP에 같은 수정 코드를 담아요. 다른 OBS 설치 위치·포터블 설정과 기존 데이터 보존 검증을 유지해요.
- 자동 설치는 추가 장면 모음·독·시작 스크립트를 연결하고, 방송 프로필·해상도·FPS·인코더·오디오·방송 키를 바꾸지 않아요.

## HF-12 · 웹 의존성 보안 패치

- 웹 Blob SDK를 2.8.2로 갱신하고, 하위 의존성 Undici는 6.29.1, Zod는 4.6.6 이상을 사용하도록 잠금 파일을 갱신했어요.
- 상위 CLI 설정 패키지가 이전 Zod 버전을 고정하고 있어 해당 경로에 범위를 지정한 override를 적용했어요.
- 2026-10-24 기준 `npm --prefix web audit`에서 보고된 취약점은 0건이에요. 인증·저장 공간·사용자 키·목록은 변경하지 않아요.
