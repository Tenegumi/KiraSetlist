OBS에서 바로 조작해요

이 PC에는 연결이 끝났어요. OBS의 키라 앰프 DLC 독에서 곡을 골라 주세요.

오늘 부를 노래를 담기

노래책에서 제목이나 가수를 검색하고 추가를 눌러요. 없는 노래는 직접 입력에서 제목과 가수를 적으면 돼요. 앨범아트가 없으면 기본 키라 LP가 나와요.

노래를 시작하고 넘기기

목록의 부르기로 현재 곡을 정해요. 다 부르면 다음 / 완료를 눌러요. 실수했다면 되돌리기로 돌아가요.

방송 화면에 맞추기

화면 설정에서 앰프의 크기와 투명도를 조절해요. 이전곡 표시를 끄고 다음곡 수를 0으로 하면 현재 곡만 보여요. 왼쪽 자막과 LP도 각각 켜고 끌 수 있어요.

다른 PC에서 처음 연결할 때

  1. OBS → 도구 → 스크립트 → +에서 설치 폴더의 kira-amplifier-dlc.lua를 선택해요.
  2. 독 → 사용자 지정 브라우저 독에서 이름을 키라 앰프 DLC로 적고, 설치 폴더의 dock-launcher.html 파일 주소를 넣어요.
  3. 장면에 브라우저 소스를 추가하고 로컬 파일로 overlay-launcher.html을 선택해요. 너비 3840, 높이 2160, 사용자 지정 FPS 60으로 설정해 주세요. 소스 우클릭 → 변환 → 화면에 맞추기로 방송 화면에 맞춰요. 4K로 그린 다음 줄이면 움직이는 글자도 더 선명해요.

예시 배경 소스는 실제 방송에서 숨겨 주세요. 기존 버전은 별도 장면 모음과 기존 독으로 계속 사용할 수 있어요.
