주소 두 번 붙이면,
준비 끝.

설치 프로그램이나 로컬 서버를 켤 필요가 없어요. 인터넷 연결은 필요해요.

  1. 첫 화면에서 ‘내 방송 공간 만들기’를 눌러요.조작 독 주소와 방송 화면 주소가 생겨요. 기존 로컬 버전의 주소와 달라요.
  2. OBS → 독 → 사용자 지정 브라우저 독이름은 ‘키라 웹 셋리스트’. 조작 독 주소를 붙이고 적용해요.
  3. OBS → 소스 목록의 + → 브라우저방송 화면 주소를 붙여요. 너비 3840, 높이 2160으로 설정하고 사용자 지정 프레임 속도를 60으로 맞춰요. 소스를 장면에 맞게 축소해요.
  4. 독의 노래책에서 + 버튼으로 곡을 추가해요.오늘의 리스트에서 ‘부르기’를 누르면 방송 화면에 나타나요. 노래책에 없는 곡은 ‘직접 추가’로 넣어요.
  5. 노래가 끝나면 ‘완료 · 다음 곡’을 눌러요.원본·앰프 DLC 디자인, 우측 창 크기와 표시할 곡 수도 독에서 바꿔요.

조작 독은 이렇게 보여요.

원본 · 앰프 DLC 방송 화면

위 이미지는 웹 버전을 실행해 캡처한 예시예요. 실제 방송 소스에는 캐릭터 배경이 포함되지 않아요.

조작 주소는 본인만 보관해 주세요. 방송 화면 주소에는 읽기 권한만 있어요. 곡 목록은 서버에 저장돼요.

현재 노래책은 등록본 211곡이에요. Notion 자동 동기화는 연결 전이에요. 음원 재생과 가사는 포함하지 않아요.
