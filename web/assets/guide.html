방송에 붙여 보자!

OBS를 다룰 줄 알면 충분해요. 아래에서 편한 방법을 골라요.

1. 웹으로 연결다운로드 없이 주소 두 개만 붙여요.2. 내 PC에 설치ZIP을 받아 직접 연결해요.

1. 웹으로 연결하기

웹 버전은 다운로드가 필요 없어요. 한 번 연결하면 곡 고르기와 화면 설정은 OBS 독에서 해요. 인터넷 연결은 필요해요.

남궁우와 한 단계씩

전체 순서를 한눈에 보기
  1. 첫 화면에서 OBS 입력할 링크 발급하기를 눌러요.
  2. 독 주소를 독 → 사용자 지정 브라우저 독에 붙여요.
  3. 방송 주소를 소스 → + → 브라우저에 붙여요. 3840×2160 / 60fps로 설정해요.
  4. 소스를 우클릭해 변환 → 화면에 맞추기를 눌러요.
  5. 노래책에서 +로 담고, 리스트에서 부르기를 눌러요.
  6. 다 부르면 완료 · 다음 곡. 원본·앰프 DLC와 크기는 독에서 골라요.

독 주소와 방송 주소는 서로 달라요. 독 주소는 본인만 보관하고, 다음 방송에서도 같은 주소를 써요. 새로 발급하면 별도의 빈 리스트가 만들어져요.

노래책은 매일 한국 시간 새벽에 Notion에서 갱신해요. 새 곡과 수정된 정보를 반영하고, 삭제된 곡도 보존해요. 읽기에 실패하면 마지막으로 저장한 목록을 유지해요. 직접 추가한 곡과 오늘의 리스트는 이 갱신으로 지워지지 않아요.

OBS 입력할 링크 발급하러 가기 →먼저 눌러보기 ↗

2. 내 PC에 설치하기

웹 대신 기존 Windows 로컬 버전을 쓸 수도 있어요. ZIP 안에 필요한 실행 파일이 들어 있어요. 프로그램 개발 도구를 따로 설치할 필요는 없어요.

수동 ZIP 받기 ↓남궁우의 로컬 그림 가이드 ↗
  1. ZIP을 받고 모두 압축 풀기를 해요.
  2. OBS 도구 → 스크립트 → +에서 kira-unified.lua를 골라요.
  3. 가이드에 있는 로컬 주소를 조작 독과 브라우저 소스에 각각 붙여요.
  4. 브라우저 소스는 3840×2160 / 60fps. 화면에 맞추기를 눌러요.

폴더는 연결한 뒤 옮기지 않아요. 로컬판의 노래책은 ZIP에 담긴 등록본이며 웹의 매일 자동 갱신과 별개예요. 웹과 로컬의 개인 리스트도 별도로 저장돼요.

자동 설치를 더 선호한다면

로컬 방식 안에서도 수동 연결과 자동 설치 중 고를 수 있어요. 자동 설치는 OBS를 닫고 실행해요. 새 장면 모음과 독·시작 스크립트를 등록하며, OBS 설정을 먼저 백업해요. 방송 해상도·FPS·방송 키·인코더·오디오 설정은 바꾸지 않아요.
