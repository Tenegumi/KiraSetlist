# 키라 웹 셋리스트

설치 없이 OBS의 사용자 지정 브라우저 독과 브라우저 소스를 연결하는 웹 버전입니다. 기존 로컬 배포는 변경하지 않습니다.

첫 화면에서 방송 공간을 만들면 조작 독 주소와 읽기 전용 방송 화면 주소가 생성됩니다. 곡 목록과 원본·앰프 DLC 선택은 Vercel의 비공개 Blob에 저장됩니다. 변경은 약 1초 간격으로 확인합니다. 노래책은 기존 211곡 등록본이며 Notion 자동 동기화는 아직 구현하지 않았습니다.

배포 전에 저장소 루트에서 `npm --prefix web install`과 `npm --prefix web run build`를 실행합니다. 빌드는 기존 앱의 화면·폰트·노래책을 `web/source`에 준비합니다. 개인 상태, Node 실행 파일, OBS 설정은 업로드하지 않습니다. Vercel 프로젝트의 루트는 `web`, Node.js는 24입니다. 비공개 Blob 저장소를 연결하여 `BLOB_READ_WRITE_TOKEN`을 설정한 후 배포합니다.

조작용 키와 보기용 키는 URL의 fragment에 저장하며 API 인증 헤더로 전송합니다. 보기 주소로 변경·백업 요청은 거절합니다. 상태 저장은 ETag 조건부 쓰기로 충돌을 감지합니다. 웹 버전의 직접 이미지 업로드는 650KB 이하로 제한합니다.
