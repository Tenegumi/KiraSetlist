# 키라 웹 셋리스트

설치 없이 OBS의 사용자 지정 브라우저 독과 브라우저 소스를 연결하는 웹 버전입니다. 기존 로컬 배포는 변경하지 않습니다.

첫 화면에서 **OBS 입력할 링크 발급하기**를 누르면 조작 독 주소와 읽기 전용 방송 화면 주소가 생성됩니다. 곡 목록과 원본·앰프 DLC 선택은 Vercel의 비공개 Blob에 저장됩니다. 독에서 곡을 추가하면 목록에 바로 담기고 방송 화면은 약 1초 간격으로 변경을 확인합니다.

Notion 공개 노래책은 Vercel Cron으로 매일 갱신합니다. UTC 19시 일정이며 한국 시간 새벽 4시대에 실행됩니다. Hobby 일정은 해당 시간대 안에서 실행 시점이 달라질 수 있습니다. 페이지 ID로 곡을 합쳐 새 곡·수정만 반영하고, 삭제된 곡과 기존 앨범 아트는 보존합니다. 개인 방송 공간은 변경하지 않습니다. 조회 실패·불완전한 응답은 저장하지 않아 마지막 성공 목록을 유지합니다. 이 조회는 Notion 공개 페이지의 내부 조회 API를 사용하므로 페이지 공개 설정이나 구조가 바뀌면 수정이 필요할 수 있습니다.

`CRON_SECRET`을 Vercel Production 환경의 비밀 값으로 설정해야 합니다. 예약 요청은 Bearer 키로 인증되며 임의 방문자가 갱신을 실행할 수 없습니다. 공개 `/api?op=catalog`는 마지막 갱신 시각과 결과를 제공합니다. 열린 독의 노래책은 변경을 60초 안에 확인합니다. Notion 편집 즉시 동기화하는 방식은 아닙니다.

배포 전에 저장소 루트에서 `npm --prefix web install`과 `npm --prefix web run build`를 실행합니다. 빌드는 기존 앱의 화면·폰트·노래책을 `web/source`에 준비합니다. 개인 상태, Node 실행 파일, OBS 설정은 업로드하지 않습니다. Vercel 프로젝트의 루트는 `web`, Node.js는 24입니다. 비공개 Blob 저장소를 연결하여 `BLOB_READ_WRITE_TOKEN`을 설정한 후 배포합니다.

조작용 키와 보기용 키는 URL의 fragment에 저장하며 API 인증 헤더로 전송합니다. 보기 주소로 변경·백업 요청은 거절합니다. 상태 저장은 ETag 조건부 쓰기로 충돌을 감지합니다. 웹 버전의 직접 이미지 업로드는 650KB 이하로 제한합니다.
